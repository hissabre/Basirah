# basirah-core
Cœur partagé de Basirah (TypeScript) : base du Coran, alignement, stabilisation, machine d'états, capture audio. Lire `docs/` dans l'ordre. `npm test` pour les vérifications.
Licence des données : le texte arabe vient de Tanzil (licence non commerciale) — à remplacer/licencier avant tout produit commercial.

## Démarrage rapide
Voir `docs/SETUP.md` (installation, essai Zipformer), `docs/09-PLATFORMS.md` (autres plateformes) et `TODO-HAMADOUN.md` (ce qui dépend de vous). **Tous les tests fournis sont simulés ; aucun résultat de reconnaissance réelle n'existe encore.**
